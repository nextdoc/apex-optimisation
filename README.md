# Apex Optimisation

A Salesforce project that works with scratch orgs. It holds example code showing techniques for improving Apex.

## Examples

- `apex/fast-testing.apex`: the same Account revenue logic written three ways (imperative, imperative shell, functional core), run through shared tests and timed side by side.

## Scratch org

To create a scratch org, run:

```bash
./create-scratch-org.sh <alias> [dev-hub-alias]
```
